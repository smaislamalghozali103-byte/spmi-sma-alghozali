# SOP Pelaksanaan SPMI (Siklus PPEPP)

**Kode Dokumen: SOP/SPMI/SMAAG/2026/001**

**1. Tujuan**
Menjamin pelaksanaan siklus PPEPP (Penetapan, Pelaksanaan, Evaluasi, Pengendalian, Peningkatan) berjalan efektif.

**2. Langkah Kerja**
1. **Penetapan:** Tim SPMI menetapkan standar mutu berdasarkan Rapor Pendidikan.
2. **Pelaksanaan:** Guru dan staf menjalankan program sesuai RKT.
3. **Evaluasi:** Tim Monev melakukan observasi dan evaluasi.
4. **Pengendalian:** Kepala Sekolah memimpin rapat tinjauan manajemen.
5. **Peningkatan:** Tim SPMI menyusun RTL untuk tahun berikutnya.
